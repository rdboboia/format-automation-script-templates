# FAST - Format automation script templates
This is a personal project that I'm currently working on to automate as much as possible the configuration and program installation on a frash windows install.
As I've already mentioned, this is something personal: my desired programs, my desired settings, etc.
However, I think that some of my work can be useful for the rest of the world, so feel free to check it out and use it if any script fits your needs :)

# Current state
This project is still in a very early state. I've been working on it for a week now almost non-stop, but there is still a lot of work to do.
